第一次联机

  1. 安装并准备身份

    从下载页面了解对应系统的完整安装包。打开客户端后选择语言，再登录账号；服务允许时也可以填写昵称，以访客身份开始。

  2. 创建或加入房间

    在“我的房间”选择创建房间，设置名称和游戏，再邀请朋友。如果朋友已经建好房间，粘贴对方分享的邀请码即可加入。一个账号同一时刻在一台设备上联机。

  3. 等待网络就绪

    进入房间后查看成员和网络状态。正在准备网络时先等待；若持续无法就绪，按照页面的恢复提示检查，或打开网络诊断。

  4. 从游戏中找到伙伴

    大家使用兼容的游戏版本。房主在游戏内开启局域网或对应服务器，其他人在游戏的局域网列表寻找，或输入房主的虚拟 IP 与游戏端口。

COMMON QUESTIONS

常见问题

一些开始之前、
联机之中常遇到的问题。

支持所有游戏吗？

适用于支持局域网或直接 IP 连接的游戏。游戏版本、监听端口、防火墙和服务端规则都可能影响连接；不承诺对所有游戏、反作弊或网络环境通用兼容。

进了房间，为什么游戏里找不到朋友？

先确认房间网络已就绪、房主已在游戏中开放局域网，并核对游戏版本和端口。有些游戏不会自动列出其他成员，可以尝试虚拟 IP 直接连接，再通过网络诊断查看实际状态。

邀请码失效了怎么办？

请房主确认房间仍有效，并重新生成邀请。邀请码是加入房间的凭据，仅分享给希望一起玩的朋友。

关闭窗口会断开连接吗？

关闭窗口后网络后台继续运行，界面会收至托盘；没有可用托盘时最小化。希望退出联机时，请在房间中使用离开房间操作。

账号登录和访客有什么区别？

正式账号可在服务开放登录时，通过浏览器完成验证并管理授权设备。访客身份与本机设备关联，丢失身份后不能只凭昵称恢复；可在账号页查看绑定入口。

延迟显示“—”或链路未知是什么意思？

当前没有可用的真实测量或隧道信息。界面不会用推测结果补齐。检查对方是否在线、游戏网络是否就绪，并查看网络诊断。

可以用来代理所有互联网流量吗？

NodeLane Room 聚焦房间内的游戏局域网通信，不提供互联网出口代理。网络需要允许 UDP；完全封禁 UDP 时无法通过 TCP 回退联机。
