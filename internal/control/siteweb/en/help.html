QUICK START

Your first game together

  1. Install and sign in

    Visit the download page to find the complete installer for your system. Open the client, choose a language, then sign in. Where the service allows it, you can also enter a display name and start as a guest.

  2. Create or join a room

    In My rooms, create a room, choose its name and game, then invite your friends. If a friend has already created one, paste their invitation code to join. An account can play on one device at a time.

  3. Wait for the network

    Check the members and network status after joining. Wait while the network is being prepared. If it does not become ready, follow the recovery steps shown in the client or open network diagnostics.

  4. Meet inside the game

    Use compatible game versions. The host opens a LAN game or server; other players can find it in the game's LAN list or connect using the host's virtual IP and game port.

COMMON QUESTIONS

A little help
along the way.

Answers for before you start
and while you play.

Does it work with every game?

It is designed for games that support LAN or direct IP connections. Game versions, listening ports, firewalls and server rules can affect connectivity. Compatibility with every game, anti-cheat system or network environment is not guaranteed.

I joined the room. Why can't I find my friends in the game?

Check that the room network is ready and the host has opened a LAN game, then compare game versions and ports. Some games do not list other players automatically. Try connecting to the virtual IP directly and use network diagnostics to check the actual connection.

What if an invitation has expired?

Ask the host to check that the room is still active and create a new invitation. An invitation code grants access to a room; share it only with friends you want to play with.

Does closing the window disconnect me?

The network service keeps running when you close the window. The interface moves to the system tray, or minimizes if no tray is available. To stop playing in the room, use Leave room in the client.

How is signing in different from using a guest account?

When account sign-in is enabled, you can verify your account in a browser and manage authorized devices. A guest identity is tied to the local device and cannot be recovered from a display name alone if it is lost. Check the Account page for the option to link an account.

Why does latency show “—”, or the connection show as unknown?

No current measurement or tunnel information is available. The client does not fill in missing data with estimates. Check whether the other player is online, whether the game network is ready, and what network diagnostics reports.

Can I use it to proxy all internet traffic?

NodeLane Room focuses on game LAN traffic within a room. It does not provide an internet exit proxy. Your network must allow UDP; there is no TCP fallback when UDP is completely blocked.
